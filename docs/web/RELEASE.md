# Versões das docs

Cada versão é uma seção `## X.Y.Z · data`, escrita na `release/X.Y.Z` junto com o bump. O
`web-deploy.yml` publica essa seção como texto da release do GitHub; sem ela, a release não sai.

## 1.2.1 · 28 nov 2026

- **Idioma na URL:** as docs ficam em `/pt-br` e `/en`.
- **Tema e idioma que seguem você:** escolheu claro ou escuro, português ou inglês, e todos os
  sites Acerola abrem do mesmo jeito.
